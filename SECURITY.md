# Security policy

Njörun is currently at the planning stage. No firmware or Home Assistant
integration has been released, so there are no supported product versions yet.

Report a suspected vulnerability through
[GitHub private vulnerability reporting](https://github.com/metaneutrons/njorun/security/advisories/new).
Do not disclose vulnerability details in a public issue or pull request. If
private reporting is unavailable, contact a repository maintainer privately
through GitHub without posting technical details publicly.

We aim to acknowledge a report within five business days. Investigation and
remediation timing depends on the issue and the evidence available.
