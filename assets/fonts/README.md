# Inter 4.1

Unmodified regular, medium and semibold TrueType files from
https://github.com/rsms/inter/releases/download/v4.1/Inter-4.1.zip.
Copyright Rasmus Andersson; distributed under the SIL Open Font License in LICENSE.txt.

Both simulator and embedded Slint builds import these files explicitly, so text metrics
do not depend on fonts installed on the build host.
