# Material Design Icons

Subset of Pictogrammers Material Design Icons from
[MaterialDesign-SVG 9e04201d](https://github.com/Templarian/MaterialDesign-SVG/tree/9e04201d4557e729822fb57f62a316c3dea1d4a8).
SVG files are unmodified upstream inputs. Icons are Apache-2.0; upstream
license notice and the full Apache-2.0 terms accompany them.

The simulator uses these for supported domain defaults and a bounded icon fallback.
This does not yet include the entire HA-selectable MDI catalog.

The room-*.svg, scene-sparkle.svg and sensor-presence.svg files are original
Njörun line drawings, licensed under Apache-2.0. They use a consistent 24-unit
grid and 1.7-unit rounded stroke.
